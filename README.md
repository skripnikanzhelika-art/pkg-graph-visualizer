# Инструмент визуализации графа зависимостей (Вариант 22)

Программа на Python для анализа зависимостей пакетов PyPI (pip).

## Структура
- `src/` — исходный код
- `tests/` — тесты
- `config.yaml` — конфигурация
- `run.bat` — скрипт запуска для Windows

## Запуск
Дважды кликните `run.bat` или выполните:
```bash
python src/prog.py
